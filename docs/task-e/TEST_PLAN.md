The app declares `minSdk 24`; Android's [PBKDF2 factory support table](https://developer.android.com/reference/javax/crypto/SecretKeyFactory) lists SHA1 from API 10 and SHA256 from API 26. The versioned implementation creates SHA1 records on API 24–25 and can verify older SHA256 records there through the [HmacSHA256 MAC](https://developer.android.com/reference/javax/crypto/Mac). API 24, API 25 and API 35 now have real emulator authentication PASS results; the full order workflow was executed on API 35. The original 35-case matrix remains 35 PASS, 0 PENDING, 0 FAIL; the three authentication regression rows are supplementary evidence outside that matrix.
